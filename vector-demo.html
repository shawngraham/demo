Token IDs → Token + Position Lookup → 6× Self-Attention Layers → Contextual Token Vectors
Why doesn't one token ID always get the same vector? Across 6 self-attention layers, every token mixes signals from all neighboring tokens. Plus, all-MiniLM-L6-v2 was fine-tuned via contrastive learning on ~1B sentence pairs so similar meanings align in cosine space.

Careful: Individual dimensions (#0…#383) do not mean single human concepts (e.g. Dim #42 is not "animals"). Meaning is encoded distributed across patterns of all 384 dimensions working together.
